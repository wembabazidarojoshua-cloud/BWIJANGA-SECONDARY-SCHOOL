# Bwijanga Secondary School Portal — Starter

This is a front-end prototype containing:
- `index.html`: public homepage and portal entry cards
- `admin.html`: administrator dashboard preview

## Important
This prototype is not connected to secure authentication or a database. Do not enter real student, teacher, financial, or other confidential information.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Find Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose `main` and `/ (root)`, then Save.
5. Wait for the deployment link to appear.

A secure production portal needs a backend, authentication, role-based permissions, and appropriate privacy protections.
